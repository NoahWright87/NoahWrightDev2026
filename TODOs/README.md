# TODO Workflow

This directory holds feature planning files for the NoahWrightDev2026 site.

## Naming

Files follow the pattern `{feature-name}.todo.md`.

## Lifecycle

1. **Create** a `{feature-name}.todo.md` file when a feature is ready to plan.
2. **Work** through the checklist. Mark tasks with `[x]` when done.
3. **Delete** the file when all tasks are verified and the feature ships.

## File Format

Each file should include:

```
# Feature Name

## Goal
One sentence of intent.

## Scope In
Bulleted list of what is included.

## Scope Out
Bulleted list of what is excluded (prevents scope creep).

## Dependencies
Other features/phases that must be done first.

## Tasks
- [ ] Task one
- [ ] Task two

## Verification
How to confirm each task is done.

## Done When
Clear statement of when this TODO file can be deleted.
```
